# Clairvoyance Canvas Templates

Starting layouts for [Clairvoyance](https://www.clairvoyanceai.com) canvases, shown in the sidebar's **New Canvas** menu.

## Install

Copy a `.json` file into `config/canvas-templates/` in your Clairvoyance data folder (Windows: `%APPDATA%\clairvoyance\config\canvas-templates\`), then restart Clairvoyance. Give your own variations a new file name, because files that ship with the app are refreshed on launch.
